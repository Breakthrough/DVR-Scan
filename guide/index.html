    User Guide¶

    After installation, launch the DVR-Scan application from its shortcut, or by running dvr-scan-app from a terminal (dvr-scan-app.exe in the portable version).

    DVR-Scan has two views:

    • Scan Wizard: walks you through a scan step by step (add videos, pick a preset, choose an output folder, and scan).
    • Advanced Mode: shows all input, region, output, and detection settings in a single window.

    You can switch between them at any time using the Advanced Mode button in the wizard, or File -> Scan Wizard in Advanced Mode. To change which view opens by default, use File -> Startup Mode in either view (new installs start in the wizard, while existing installs keep Advanced Mode; see startup-mode for details).

    For the dvr-scan command-line interface and config file options, see the Documentation page.

    Scan Wizard¶

    The wizard opens on the Add Videos step. Click the drop zone (or drag and drop files onto the window) to add one or more videos, then press Next:

    Next, pick a Preset. Default uses your saved settings, High Sensitivity catches faint or small motion, Low Sensitivity reduces false detections, and Fast Scan trades accuracy for speed (see Presets for the settings each one changes). You can also adjust the sensitivity threshold directly, where lower values detect smaller amounts of motion (if motion you expect is not detected, see this FAQ entry):

    On the Choose Output step, select how events should be saved (or Scan Only to just produce a report), review your choices, and press Start Scan. The scan runs in place, and the detected events are listed when it finishes:

    Advanced Mode¶

    Advanced Mode gives you direct access to all scan settings, the Region Editor, and start/end times in a single window. Add one or more videos by clicking the Add button or dragging and dropping files onto the window:

    You can select several videos at once with Shift-click, Ctrl-click, or Command-click on Mac. Select every video with Ctrl + A (Command + A on Mac). To remove the selected videos, use the Delete key or the Remove button. These actions are also available from the Edit menu.

    To extract and save the motion events from the input, click the Start button. You will be prompted for a location to save the events to, after which scanning will begin in a separate progress window. Once complete, each event will be saved to the output folder you selected.

    To tune motion sensitivity, go to Settings -> Motion and adjust the threshold, where lower values are more sensitive to motion and higher values are less sensitive. You can also adjust event settings and more:

    See the config option documentation for a detailed description of each setting.

    Region Editor¶

    The Region Editor allows you to limit motion detection to specific areas of the frame. In Advanced Mode, once you have a video loaded, check Set Regions and press the Region Editor button (or run dvr-scan -i video.mp4 -r from the command line):

    You can use the mouse to add or move points when editing regions. Left click to add a new point, or drag an existing one. Right click can be used to delete a point, and to add/remove shapes.

    To begin scanning, close the region editor, and click the Start button. You will be prompted to save the regions you have created before scanning so you can re-use them if required.

    Regions¶

    Regions are a set of points creating a closed shape. A rectangle will be created by default for you to modify.

    Regions are edited individually, but all regions are used when scanning. To add a new shape, right click anywhere on the frame.

    Regions can be selected using the Active Region selector at the bottom left, or cycled by using the Tab key. Note that only one region can be edited at a time.

    By enabling mask mode (Toggle Mask at the bottom right), you can see the exact areas of the frame that DVR-Scan will consider for motion:

    Regions can be saved/loaded for reusing across videos or editing via the File menu.

    Controls¶

    Click Help -> Show Controls or press Ctrl + H (Command + H on Mac) to display all keyboard and mouse controls. You can move the canvas by holding Ctrl (Command on Mac) and dragging with left-click. The cursor icon should change depending on what mode the editor is in.

    Most actions have keyboard shortcuts displayed beside the menu item. You can undo/redo any modifications or deletions when working on the regions by clicking Edit -> Undo/Redo or using your system's undo/redo keys.
